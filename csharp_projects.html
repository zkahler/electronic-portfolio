SportsPro Web Application

CIS 296 – Advanced MS Web Development

SportsPro is a full-stack ASP.NET Core MVC web application built for managing sports product registrations, customer records, incidents, and technician assignments. The project was developed incrementally across multiple assignments, with each phase adding new functionality and architectural improvements.

Key features include a complete customer CRUD system with robust server-side data validation, a product registration system using a many-to-many database relationship, and a data layer refactored to use the Repository and Unit of Work patterns for clean separation of concerns. The app uses ASP.NET Core Identity-style session state to persist the selected customer across pages.
