The Green Meeple

CIS 241 – Dynamic Website Development

The Green Meeple is a full-stack board game management web application built with PHP and MySQL. Users can browse a catalog of over 70 board games, add new titles, edit existing entries, and manage a shopping cart — all backed by a live MySQL database.

The app is structured around the MVC pattern with a PDO database layer, a controller handling all CRUD operations, and separate view templates for each page. It also includes a user registration and login system with password hashing, a filter and search interface, and a persistent cart stored in session state.
